# CS 210 Portfolio

## Project Summary
For this project, I built a grocery tracking program in C++. The program reads grocery items from a file, counts how many times each item appears, lets the user search for a specific item, prints all the item frequencies, and creates a backup file with the results. The main goal was to practice working with classes, files, maps, and writing a program that actually solves a real problem.

## What I Did Well
I think I did a good job keeping my code organized by breaking it into different files and functions instead of putting everything in one place. That made it easier to read, test, and fix when something wasn't working. I also made sure the program matched all of the project requirements.

## Areas for Improvement
If I were to keep working on this project, I'd make the menu look a little nicer and add better input validation so it handles bad user input better. I'd also make searching ignore uppercase and lowercase letters. Those changes would make the program easier to use and a little more professional.

## Challenges
The hardest part for me was figuring out how to use maps with file input to keep track of the grocery item counts. I got through it by breaking the problem into smaller pieces, testing one function at a time, and using the course resources whenever I got stuck. I also learned how helpful debugging can be instead of just guessing what's wrong.

## Transferable Skills
This project helped me get more comfortable with C++, object-oriented programming, reading and writing files, debugging, and organizing larger programs. Those are all skills I'll use again in future classes and eventually in software development.

## Maintainability
I made the program easier to maintain by separating the code into classes and functions, using descriptive names, and keeping everything organized. That way it would be much easier to come back later and add new features or make changes without rewriting the whole program.
